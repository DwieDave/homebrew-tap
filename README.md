# DwieDave Tap

## How do I install these formulae?

`brew install dwiedave/tap/<formula>`

Or `brew tap dwiedave/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dwiedave/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
